# Métodos Directos e Iterativos para Sistemas de Ecuaciones Lineales

Implementación en Python desde cero (sin funciones de resolución de bibliotecas) para la comparación de métodos numéricos aplicados a la conducción de calor (ecuación de Laplace 2D) y sistemas tridiagonales (ecuación de Poisson 1D).

- **Autor:** Leaño Zeballos Joaquín
- **Universidad:** Universidad Mayor Real y Pontificia de San Francisco Xavier de Chuquisaca (USFX)
- **Carrera:** Ingeniería de Sistemas
- **Asignatura:** Métodos Numéricos (4.º semestre)

## Contenido del cuaderno
- **Experimento 1:** Eliminación de Gauss con pivoteo parcial, Jacobi, Gauss-Seidel y SOR ($\omega$ óptimo) en mallas de $N = 100, 400, 900$ incógnitas.
- **Experimento 2:** Comparación de tiempos entre Gauss con pivoteo parcial y el Algoritmo de Thomas (TDMA) en sistemas tridiagonales de hasta $N = 1200$ incógnitas.
